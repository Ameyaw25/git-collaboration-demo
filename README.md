# Git & GitHub Collaboration Demo

## 1. Project Overview

This project demonstrates how professional developers collaborate safely on one codebase using Git and GitHub. It is a simple webpage that explains the importance of collaboration in software development.

## 2. Technologies Used

- **HTML:** Structures the webpage content.
- **CSS:** Styles the webpage and controls its appearance.
- **Git:** Tracks code changes and maintains the project history.
- **GitHub:** Hosts the repository and supports collaboration through branches, pull requests, issues, and code reviews.

## 3. Project Files

- `index.html` — Contains the webpage structure and content.
- `style.css` — Contains the webpage styling.
- `README.md` — Documents the project and collaboration workflow.

## 4. Collaboration Workflow

1. **Repository:** Create a central repository on GitHub to store the project.
2. **Branch:** Create a separate branch for a new feature or improvement.
3. **Commit:** Save changes with a descriptive commit message.
4. **Push:** Upload the branch to GitHub.
5. **Pull request:** Propose changes to the main branch.
6. **Code review:** Inspect the proposed changes before accepting them.
7. **Merge:** Integrate approved changes into the main branch.
8. **Issue tracking:** Record bugs, tasks, and proposed improvements using GitHub Issues.

## 5. Example from This Project

A branch named `feature-homepage` was created to add a section titled "Why Collaboration Matters" to the webpage. The change was committed, pushed to GitHub, submitted through a pull request, reviewed, and merged into `main`.

## 6. Conclusion

Git and GitHub help developers manage changes, work on separate branches, review contributions, track issues, and maintain a reliable project history. These practices make software development more organised and collaborative.
